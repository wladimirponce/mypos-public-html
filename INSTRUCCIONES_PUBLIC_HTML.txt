Distribuible directo a public_html
==================================

Sube TODO el contenido de esta carpeta directamente a:

/home/TU_USUARIO/public_html/

Despues de subir:

1. Copia public_html/api/.env.example como public_html/api/.env.
2. Edita DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD y JWT_SECRET.
3. Aplica las migraciones pendientes desde phpMyAdmin/cPanel antes de reemplazar el runtime.
   El paquete productivo no incluye un instalador web.
4. Prueba https://www.mypos.cl.
5. Configura cPanel Setup Python App:
   - Application root: /home/TU_USUARIO/public_html/agent
   - Application URL: /agent
   - Startup file: passenger_wsgi.py
   - Entry point: application
   - Variables: las de public_html/agent/.env.example, con AGENT_SECRET igual al de public_html/api/.env.

Notas:
- Este distribuible usa /api en el mismo dominio; no requiere api.mypos.cl.
- Incluye public_html/agent para el Agente IA; no subas ni copies un .env local con secretos.
- Si antes copiaste el agente dentro de public_html/api, este deploy Git limpia los archivos Python mal ubicados: api/graph, api/tools, api/persistence, api/config.py, api/main.py y api/passenger_wsgi.py.
- No borres public_html/api/.htaccess.
- Activa "Show Hidden Files" en cPanel para ver .htaccess y .env.example.
